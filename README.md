# ورشة اللغة — تعلّم الأوردو

أداة شخصية لتعلّم مصطلحات الأوردو العملية، تعمل بالكامل من المتصفح (بدون خادم) وتُنشر عبر GitHub Pages.

## تفعيل الصفحة (مرة واحدة فقط)

1. ادخل إلى إعدادات المستودع على GitHub: **Settings → Pages**.
2. تحت **Build and deployment → Source** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/ (root)**، ثم اضغط **Save**.
4. بعد دقيقة أو دقيقتين سيظهر رابط الصفحة أعلى نفس الإعداد (على شكل
   `https://newsaleh.github.io/UrduLearning/`).

## تفعيل المزامنة مع GitHub (لمتابعة تقدّمك من أي جهاز)

الأداة لا تحتوي على خادم خاص بها، لذلك تتصل مباشرة بواجهة GitHub API من متصفحك
لحفظ ملف `data/progress.json` وتحديثه في هذا المستودع. لتفعيل ذلك:

1. من حسابك على GitHub: **Settings → Developer settings → Personal access tokens
   → Fine-grained tokens → Generate new token**.
2. في **Repository access** اختر **Only select repositories** وحدد هذا المستودع
   فقط (`UrduLearning`).
3. في **Permissions** فعّل **Contents: Read and write** فقط، ولا تفعّل أي صلاحية
   أخرى.
4. انسخ الرمز، وافتح تبويب **"البيانات والمزامنة"** في الصفحة، والصقه في حقل
   **Personal Access Token**، ثم اضغط **حفظ الإعدادات**.
5. كرّر هذه الخطوة على أي جهاز آخر تريد المتابعة منه — كل جهاز يحتاج الرمز مرة
   واحدة فقط، وبعدها تُحفظ التغييرات تلقائيًا وتُقرأ أحدث نسخة عند فتح الصفحة.

الرمز يُحفظ في متصفحك فقط (localStorage) ولا يُخزَّن أبدًا داخل المستودع نفسه.

## سماع النطق

الأداة لا تنطق الجمل بنفسها (أصوات المتصفحات لا تدعم الأوردو بشكل موثوق على
كل الأجهزة). بدلًا من ذلك، اضغط زر النسخ 📋 بجانب أي جملة أوردو لنسخ نصها
الأصلي، ثم الصقه في [Google Translate](https://translate.google.com/?sl=ur&tl=ar)
لسماع نطقه هناك.
